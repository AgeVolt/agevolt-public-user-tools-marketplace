# AgeVolt Public User Tools Marketplace

Marketplace pre verejne alebo semi-verejne AgeVolt nastroje pre pouzivatelov.

Ma sluzit iba na obsah a pluginy, ktore su schvalene ako public-safe: verejne navody, zakladna podpora, pouzivatelske postupy, troubleshooting, verejne API alebo integracne navody.

Tento marketplace ma najprisnejsie pravidlo: nic interne sem nepatri bez explicitneho rozhodnutia. Nepatria sem interne KB, zakaznicke data, support exporty, financie, produktove plany ani neverejne technicke detaily.

Aktualny stav: pripravene ako prazdny marketplace, bez pluginov.

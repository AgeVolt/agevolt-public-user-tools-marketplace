# AgeVolt Public User Tools Marketplace

Marketplace pre verejne alebo semi-verejne AgeVolt nastroje pre pouzivatelov.

Ma sluzit iba na obsah a pluginy, ktore su schvalene ako public-safe: verejne
navody, zakladna podpora, pouzivatelske postupy, troubleshooting, verejne API
alebo integracne navody.

Tento marketplace ma najprisnejsie pravidlo: nic interne sem nepatri bez
explicitneho rozhodnutia. Nepatria sem interne KB, zakaznicke data, support
exporty, financie, produktove plany ani neverejne technicke detaily.

## Plugins

- `agevolt-portal` - read-only AgeVolt Portal MCP workflows for signed-in users.

## MCP Endpoint

- MCP: `https://api1.my.agevolt.com/mcp/agevolt/mcp`
- OAuth issuer: `https://api1.my.agevolt.com/mcp/auth`
- Web portal consent: `https://my.agevolt.com/auth/mcp-consent`
- Scope: `MCP.Access`
